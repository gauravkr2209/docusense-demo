# DocuSense: AI-Powered Documentation Summarizer

Interface demo for DocuSense, a tool that helps teachers review long final-semester student project documents.

**Note:** `index.html` is a simulated demo of the interface. It does not run a live model.

## What it solves
Teachers spend hours reading long project documents. DocuSense is designed to give a structured summary covering context, objectives, methodology, results and limitations.

## How it is used
1. A teacher uploads a student's PDF and reads the automatic summary.
2. They ask follow-up questions in chat.
3. Answers come only from that document using RAG. If the answer is not there, the assistant says so instead of guessing.

## Why it helps
Cuts review time, makes evaluation more consistent, and helps teachers prepare viva questions.

## Stack
Python, RAG, LangChain, Chroma, Ollama (free, open-source tools).
